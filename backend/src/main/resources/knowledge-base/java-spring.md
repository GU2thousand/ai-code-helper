# Java 21 与 Spring Boot 学习路线

Java 基础阶段应掌握类型系统、集合、异常、泛型、Stream、并发和 JVM 基础。每个主题都应通过小程序和自动化测试验证，而不只停留在概念记忆。

Spring Boot 项目建议采用控制层、应用服务层和基础设施层的清晰边界。控制层负责 HTTP 与参数校验，业务规则放入服务层，外部模型、数据库和第三方 API 通过适配器隔离。

Java 21 的虚拟线程适合大量阻塞式 I/O 任务，但它不会自动降低 CPU 密集型工作的成本。使用虚拟线程时仍需设置外部连接超时、并发上限和取消机制。

测试应覆盖核心业务单元测试、HTTP 契约集成测试和少量端到端测试。外部模型调用在默认测试中应由本地替身取代，避免测试依赖网络或消耗额度。
