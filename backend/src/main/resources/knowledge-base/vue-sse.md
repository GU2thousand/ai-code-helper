# Vue 3 与 SSE 实时聊天

Vue 3 聊天界面可以把消息列表、输入状态和网络状态分别建模。发送后立即显示用户消息，助手消息以增量文本更新，并明确展示连接中、已完成和失败状态。

浏览器原生 EventSource 只支持 GET，不能设置自定义请求头。跨域使用身份 Cookie 时，服务端 CORS 必须允许明确来源和 credentials，客户端则应设置 withCredentials。不要把访问令牌放进 URL，因为 URL 可能进入浏览器历史和访问日志。

SSE 服务端应设置 text/event-stream，逐段发送 message 事件，并在结束时发送 `done` 事件与 `[DONE]` 数据。浏览器关闭连接后，服务端应尽量取消上游模型流，避免继续消耗资源。

前端渲染 Markdown 时必须对 HTML 做安全处理。代码块复制、自动滚动和移动端输入区域应作为独立交互测试，而不是仅依靠手工检查。
