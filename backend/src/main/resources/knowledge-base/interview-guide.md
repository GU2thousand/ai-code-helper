# 开发岗位面试准备

项目介绍可以采用“背景—目标—约束—行动—结果—复盘”的结构。重点说明自己做出的技术决策、遇到的权衡和如何验证结果，避免只罗列技术名词。

Java 后端面试常见主题包括集合与并发、JVM、数据库索引与事务、HTTP、Spring 容器、缓存一致性以及故障排查。准备时应把概念与真实项目场景相互关联。

前端面试常见主题包括 JavaScript 事件循环、Vue 响应式原理、组件设计、网络与缓存、性能、安全和可访问性。回答时先澄清边界，再给出方案和验证指标。

模拟面试后记录不会的问题、表达不清的问题和缺少数据支撑的项目故事。下一轮只选择少数高价值薄弱点改进，并通过限时复述检查效果。
